# How AI can help DevOps apprentices develop thier skills

## 1. Learn Tools and Technologies faster
AI can act as a tutor and can explain concepts in a concise manner suited to your situation and needs.


This saves you lots of time because you don't need to read through verbose documentation to find small details, and also minimises wasted time through reading long documentation to only find out that the docs do not answer your question

## 2. Debugging and troubleshooting
There are many moving parts in DevOps, which means there are multiple points of failure. AI can help you understand error messages, and suggest potential fixes.

Although it is very important to be able to debug and troubleshoot without AI tools, the use of AI will reduce time spent on debugging and troubleshooting thus creating more time for learning new tools or features.

Using AI to help with a bug or problem can increase motivation to continue learning DevOps because being stuck on a bug is extremely draining and demotivating


## 3. Learn best practices

AI often generates different strategies of completing a task, giving you different approaches to solve a problem. You can ask AI to compare these approaches for best practice, which helps you create more robust DevOps solutions.

When using the Internet to find solutions to a problem, often times you stumble across a forum where people post their solution, however by accepting their solution, you accept their DevOps practices which may or may not be the ideal practice.

# How AI can streamline DevOps delivery

## 1. Smarter CI/CD pipelines
AI can be used to analyse pipelines to identify slow build steps, bad practices and any bottlenecks.

## 2. AI-assisted scanning (e.g. SonarQube)
AI can be used in tools such as SonarQube to detect
- Security vulnerabilities
- Bad patterns / practices
- Dependency issues
- and more

## 3. Interpreting logs
Modern applications produce huge amounts of logs. These logs have hundreds, if not thousands of lines of logs. Each line could represent an event or state. 

AI can be used to analyse the log files and summarise it. Instead of 6,000 lines of data, AI can scan and return the important bits, which may output "53 errors found, 2 root cause errors found. here's how to fix the 2 root cause errors:"
